Hands-On

PLAY PICO-8

Experience constrained game design firsthand. Each cartridge demonstrates a different aspect of the 16-color, 128×128 pixel world.

PICO-8 is a fantasy console — a virtual machine that simulates an imaginary 8-bit system with deliberate constraints: 128×128 pixel display, 16 colors, 4-channel sound, and 32KB cartridge size. These limitations aren't bugs — they're the entire point. Below are curated cartridges that each highlight a specific dimension of constrained creative design.

Use arrow keys to move, Z and X to act. On mobile, use on-screen controls.

Cart Size

PICO-8 cartridges are programmed in a subset of Lua and stored as .p8.png files — the cartridge data is literally encoded in the pixels of a 128×128 PNG image. This means a PICO-8 game is, physically, a tiny image file. The entire development environment — code editor, sprite editor, map editor, sound editor, and music tracker — runs within the same constrained virtual machine.

Below is a minimal PICO-8 program that draws the full 16-color palette to the screen — the foundation of everything you see on this site:

PICO-8 Lua
function _draw()
  cls(0)
  for i=0,15 do
    rectfill(i*8, 48, i*8+7, 79, i)
  end
  print("pico-8 palette", 24, 88, 7)
end
