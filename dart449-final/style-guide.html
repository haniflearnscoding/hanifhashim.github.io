The Revival of Retro Game Aesthetics

Used for hero titles, section labels, UI chrome, and the CRT toggle. Evokes bitmap fonts of 8-bit consoles. Sized large for legibility — never used for body copy.

Body — Source Sans 3

In an era defined by photorealistic rendering engines and 4K displays, a curious counter-movement has emerged: the deliberate embrace of low-resolution pixel art. This is not merely nostalgia — it represents a conscious design language that privileges constraint, legibility, and emotional directness over technical spectacle.

Primary reading typeface. Clean, humanist sans-serif with excellent screen rendering. Weights 300 (light), 400 (regular), 600 (semibold), 700 (bold).

Techniques

CSS Techniques

CRT Scanline Overlay

The CRT toggle (bottom-right corner) activates a full-screen overlay using a repeating linear gradient — alternating 1px transparent and 1px semi-transparent black lines. A radial gradient adds subtle vignetting at the edges, simulating the curvature of a CRT display. The effect is purely CSS with a JavaScript class toggle. Try it now!

CSS
.crt-overlay {
  background: repeating-linear-gradient(
    0deg,
    transparent,
    transparent 1px,
    rgba(0, 0, 0, 0.15) 1px,
    rgba(0, 0, 0, 0.15) 2px
  );
}

Pixel Dithering Hover Effect

Navigation links use a dithered underline on hover — a repeating linear gradient with 2px alternating color/transparent blocks. This simulates the half-tone patterns used on hardware with limited color palettes to create the illusion of additional colors.

CSS
.nav-links a::before {
  background: repeating-linear-gradient(
    90deg,
    var(--p8-red) 0px,
    var(--p8-red) 2px,
    transparent 2px,
    transparent 4px
  );
}

Parallax Starfield

The homepage hero features a three-layer parallax starfield rendered with HTML5 Canvas. Stars are drawn as 1–3px rectangles (pixelated, not circles) using PICO-8 palette colors. Each layer scrolls at a different speed on scroll via requestAnimationFrame, creating a depth effect. A deterministic PRNG ensures consistent star placement across reloads.

Scroll-Triggered Animations

All fade-in and slide-in animations use the Intersection Observer API — no scroll event listeners polling on every frame. Elements receive a .visible class when they enter the viewport, triggering CSS transitions. Staggered children use transition-delay for cascading reveals.

image-rendering: pixelated

All <img> elements use image-rendering: pixelated to ensure pixel art scales with nearest-neighbor interpolation rather than bilinear smoothing. This preserves the crisp, blocky edges that define the aesthetic.

Standards

Accessibility & Performance

Semantic HTML5: All pages use proper heading hierarchy, landmark elements (<nav>, <main>, <footer>), and descriptive alt text for images.

Zero dependencies: No frameworks, no build tools, no npm. The entire site is vanilla HTML, CSS, and JavaScript — self-contained and instantly deployable.

Responsive: Tested at 1440px, 768px, and 375px breakpoints. Flexbox and CSS Grid handle layout adaptation. Navigation, stat cards, and gallery grids reflow gracefully.

Performance: CRT overlay and parallax use requestAnimationFrame and will-change for GPU-accelerated compositing. Intersection Observer replaces scroll listeners for animation triggers.

External links: All outbound links use target="_blank" rel="noopener".
