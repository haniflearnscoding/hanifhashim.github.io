Live Coding Performance

Live audiovisual performance for Strudel and Hydra

Role Performer & Coder
Year 2025
Tools Strudel · Hydra · WebGL

About

A live performance written and executed in real time — music and visuals coded simultaneously in front of an audience.

Using Strudel for pattern-based audio and Hydra for WebGL visual synthesis, the piece was composed and performed live. The code above is running right now — the same sketch from the performance, adapted to breathe on its own without a microphone feed.

Recording

The Visuals

The Hydra sketch is built around an oscillator run through a kaleidoscope and pixelation pass. During the performance, the modulation depth, pixel grid, and feedback were driven by live audio analysis — bass frequencies pushing the geometry, mids controlling modulation depth. On this page, those values are replaced by time-based oscillations so the piece runs without a microphone.

Hydra — original (audio-reactive)

spd = 0.4
kali = 1
px = 20
sat = 2
fb = 0.1
mod = 0.3

osc(10, 0.2, 1.5)
  .color(1.2, 1, 0.8)
  .rotate(() => time * spd)
  .modulate(noise(3, 0.2).scale(() => 1 + a.fft[0] * 3), () => a.fft[1] * mod)
  .kaleid(() => kali)
  .pixelate(() => px + a.fft[0] * 40, () => px + a.fft[0] * 80)
  .posterize(6).contrast(1.8).saturate(() => sat)
  .blend(src(o0), () => fb)
  .out(o0)

// 0–3   audio reactivity, colour change
// 3–6   push kali and spd, feedback
// 6–9   osc freq change — variation of 01.hydra
