Interactivity Plan

Four key interactions planned for the final project, each reinforcing the retro game aesthetic theme through functional design choices.

Pixel-Art Hover States

Navigation links and interactive elements will use CSS-generated dithering patterns on hover, simulating the half-tone blending techniques used on hardware with limited color palettes. The effect will be achieved using repeating linear gradients at 1–2px intervals, creating an authentic low-resolution texture without image assets.

Embedded PICO-8 Web Player

The interactive page will embed playable PICO-8 cartridges using the official JavaScript web player. Visitors can play directly in the browser using keyboard controls. Each cartridge will be curated to demonstrate a specific aspect of constrained game design — color palette usage, sprite animation, or procedural generation.

Scroll-Triggered Sprite Animations

As users scroll through the essay and gallery pages, pixel-art sprite characters will animate using CSS sprite sheets triggered by the Intersection Observer API. Characters will "walk" into view, idle, or react to scroll position, adding playful visual reinforcement of the project's subject matter.

CRT Scanline Toggle

A persistent toggle button will allow visitors to overlay a CRT scanline filter across the entire site. The effect uses a CSS pseudo-element with a repeating linear gradient (1px transparent, 1px semi-transparent black) and a subtle screen curvature via border-radius. This interaction lets users physically experience the retro display aesthetic.
